# Changelog

All notable changes to this project are documented here.

## [1.0.0] — 2026-08-29

### Added

- First public release of **70 TV**.
- Editable text, font, style, size, tracking and position.
- Editable cream, orange and brown color controls.
- Three-step orange extrusion and deep brown shadow layer.
- 18-frame fade-and-scale entrance with 105.5% overshoot.
- Keyframe Stretcher support for variable clip lengths.
- `.drfx` installer, standalone `.setting`, and Effects Library thumbnails.
- Spanish and English documentation.
- Portable release validator and GitHub Actions workflow.

### Validation

- Parsed and loaded by the Fusion 21 embedded runtime.
- Tested with DaVinci Resolve Studio 21.0.3 on Linux.
