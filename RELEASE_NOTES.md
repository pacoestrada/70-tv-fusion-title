# 70 TV 1.0.0

First public release of a reusable 1970s television-style Fusion title for DaVinci Resolve 21.

## Highlights

- Native `.drfx` installer and standalone `.setting`.
- Editable text, font, size, tracking, position and three-color palette.
- Cream face with orange extrusion and brown depth.
- Smooth 18-frame fade-and-scale entrance with subtle overshoot.
- Transparent background and no third-party Fusion plugins.
- Verified with DaVinci Resolve Studio 21.0.3 on Linux.

## Installation

Download `70 TV.drfx`, open a Resolve project, go to the Fusion page and drag the file onto Resolve. Confirm installation, then find **70 TV** under **Edit → Effects Library → Titles**.

See the repository README for manual installation and full technical details.
